# IELTS 第1周词汇完整表

## 📚 词汇学习方式

### 推荐工具
1. **Anki**（免费，支持导入和同步）
   - 网站：https://ankiweb.net/
   - 优点：艾宾浩斯记忆算法，高效复习

2. **Quizlet**（免费网页版）
   - 网站：https://quizlet.com/
   - 优点：可看到别人制作的 IELTS 词汇集

3. **IELTS Vocabulary Builder**（手机 APP）
   - 可离线学习
   - 有真题例句

4. **传统方式**：买本 IELTS 词汇书，用笔记本记录
